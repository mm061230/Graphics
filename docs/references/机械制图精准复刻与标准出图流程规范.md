# 机械制图题目精准复刻与标准出图流程规范

## 0. 目标与适用范围

本文档用于规范“从拍照题图到专业结果图”的完整流程，适用于机械制图中的三视图补画、剖视图、半剖视图、局部剖视图、旋转剖视图、断面图、移出断面图、漏线补画等题型。

目标不是生成“风格相似”的图片，而是输出可审计、可复核、可打印的专业制图答案。所有最终图必须通过几何、投影、线型、剖切、版面和文件输出六类审计。

---

# 1. 总体原则

## 1.1 不使用随机生成式绘图作为最终答案

最终答案不得依赖自由生成式图片。生成式图片容易出现以下问题：

- 视图漂移；
- 中心线不共线；
- 圆心偏移；
- 比例随意变化；
- 线型不统一；
- 剖面线误入孔、槽、空腔；
- 文字和图形布局不稳定；
- 同一题反复生成结果不一致。

正确流程应为：

1. 对原图进行图像校正；
2. 提取几何基准；
3. 建立统一坐标系；
4. 用矢量几何对象重画；
5. 按机械制图规则补线、补视图、补剖面；
6. 逐项审计；
7. 输出 PNG、PDF 或 Markdown 说明文档。

## 1.2 所有图形必须有坐标依据

每一条线、每一个圆、每一道剖面线，都应来自明确的几何关系，而不是“看起来差不多”。

例如：

- 圆必须由圆心和半径确定；
- 台阶必须由水平线和垂直线确定；
- U 形槽必须由两条平行直线和相切圆弧确定；
- 中心线必须穿过圆心；
- 剖面线必须限制在实体材料区域；
- 主视图、俯视图、左视图必须由投影关系对应。

## 1.3 先基准，后轮廓，再细节

标准绘图顺序必须是：

1. 建立题目区域；
2. 建立视图区域；
3. 建立中心线和投影基准；
4. 画主要外轮廓；
5. 画孔、槽、圆台、台阶；
6. 画不可见线；
7. 画剖切线和剖面线；
8. 添加文字说明；
9. 审计；
10. 输出。

不得先画局部细节再反推整体比例。

# 2. 对用户上传图片的要求

为了保证后续复刻准确，用户提供原图时应尽量满足以下要求。

## 2.1 拍摄角度要求

优先级从高到低：

1. **扫描件最佳**；
2. 手机使用扫描软件拍摄；
3. 普通手机正对拍摄；
4. 斜拍照片仅作为最低可用输入。

拍摄时要求：

- 镜头尽量垂直于纸面；
- 题框四边完整入镜；
- 不要把纸拍成梯形；
- 不要让纸张弯曲；
- 不要从左上、右上、侧面斜拍；
- 不要让图形靠近画面边缘。

合格标准：

- 水平边基本水平；
- 垂直边基本垂直；
- 圆形看起来接近正圆；
- 题框四角都能看见；
- 图线清楚，不糊。

## 2.2 光线要求

要求：

- 光线均匀；
- 无强烈阴影；
- 无反光；
- 不要在强台灯下形成局部高亮；
- 不要让手、手机、桌面物品遮挡图形；
- 避免纸张透背严重影响识别。

合格标准：

- 图线和背景对比明显；
- 蓝线或黑线能清楚区分；
- 虚线、中心线、剖面线能看清；
- 文字题号能看清。

## 2.3 分辨率要求

建议：

- 单题图片宽度不少于 1200 px；
- 整页图片宽度不少于 2500 px；
- 不压缩发送；
- 不使用聊天软件二次压缩后的截图；
- 如果可行，上传原始照片。

最低要求：

- 圆孔边界能看清；
- 虚线能分辨；
- 剖面线方向能看清；
- 题目要求文字能读出。

## 2.4 一图一题优先

最好每次上传：

- 一题一张；
- 或同一页中上下两题清楚分开；
- 不要一次上传多张倾斜大图要求全部一次完成。

一题一图的好处：

- 透视校正更准确；
- 裁切更干净；
- 坐标提取更稳定；
- 减少误判题号和视图关系。

## 2.5 必须保留题目完整信息

图片中应包含：

- 题号；
- 题目要求；
- 已知视图；
- 剖切符号；
- A-A、B-B 等剖切标记；
- 箭头方向；
- 尺寸符号；
- 中心线；
- 虚线；
- 原有剖面线；
- 空白作图区域。

不能只拍局部轮廓，否则可能无法判断剖切方向和投影关系。

# 3. 输入图像预处理标准

## 3.1 原图备份

收到用户图片后，第一步必须保留原图，不得直接覆盖。

建议文件结构：

```text
project/
├─ input_original/
│  ├─ problem_001_original.jpg
├─ input_corrected/
│  ├─ problem_001_corrected.png
├─ extracted/
│  ├─ problem_001_crop.png
├─ vector/
│  ├─ problem_001.svg
├─ output/
│  ├─ problem_001_answer.png
│  ├─ problem_001_answer.pdf
│  └─ problem_001_report.md
```

## 3.2 透视校正

处理步骤：

1. 检测题框外边界；
2. 识别四个角点；
3. 执行透视变换；
4. 输出矩形校正图；
5. 检查边框水平和垂直情况。

审计标准：

| 项目 | 合格标准 |
|---|---|
| 上边框 | 与水平线夹角接近 0° |
| 下边框 | 与水平线夹角接近 0° |
| 左边框 | 与垂直线夹角接近 0° |
| 右边框 | 与垂直线夹角接近 0° |
| 圆形 | 校正后接近正圆 |
| 视图中心线 | 水平/垂直方向清楚 |

若纸张本身弯曲，单次透视变换可能不够，应使用局部校正或按题目局部裁切后再次校正。

## 3.3 旋转校正

如果题目整体倾斜，应进行旋转校正。

方法：

- 使用题框长边计算旋转角；
- 使用中心线计算校正角；
- 优先以题框边线为准；
- 若题框不清晰，则以主要水平中心线为准。

审计标准：

- 主水平线倾角接近 0°；
- 主竖直线倾角接近 90°；
- 多视图之间没有整体倾斜。

## 3.4 裁切题目区域

裁切原则：

- 保留题号和题目文字；
- 保留所有已知视图；
- 保留剖切符号；
- 保留作图空白区；
- 去除键盘、桌面、纸外背景；
- 不裁掉中心线延长部分；
- 不裁掉 A、B 等剖切标记。

## 3.5 线条增强

如果原图线条较浅，可进行增强：

- 灰度化；
- 对比度提升；
- 蓝色通道提取；
- 自适应阈值；
- 去噪；
- 细线增强。

注意：

- 不得把虚线增强成实线；
- 不得把剖面线吞掉；
- 不得把透背线误识别为题目线；
- 增强图仅用于辅助识别，最终答案仍需矢量重画。

# 4. 坐标系与基准建立

## 4.1 页面坐标系

以校正后的题目图为基础建立页面坐标系：

- 左上角为原点；
- X 轴向右；
- Y 轴向下；
- 单位可使用像素、毫米或自定义绘图单位；
- 所有后续元素必须记录坐标。

## 4.2 题目局部坐标系

每个题目单独建立局部坐标系：

```text
题目局部原点 = 题目区域左上角
局部 X 轴 = 题目区域水平边
局部 Y 轴 = 题目区域垂直边
```

好处：

- 不同题目互不干扰；
- 方便单题输出；
- 方便后续比例缩放；
- 方便审计。

## 4.3 视图局部坐标系

每个视图再建立视图坐标系：

- 主视图坐标系；
- 俯视图坐标系；
- 左视图坐标系；
- 剖视图坐标系；
- 断面图坐标系。

每个视图必须记录：

```text
view_id
view_type
origin_x
origin_y
width
height
center_x
center_y
scale
projection_relation
```

## 4.4 一级基准

一级基准是所有绘图的核心，不允许漂移。

包括：

- 对称中心线；
- 圆孔中心线；
- 剖切轴线；
- 主投影基准线；
- 主要底面线；
- 主要端面线。

一级基准必须先画、先锁定。

## 4.5 二级基准

二级基准用于确定细节。

包括：

- 孔边界；
- 槽边界；
- 台阶边界；
- 圆弧相切点；
- 轮廓转折点；
- 剖面边界；
- 局部剖波浪线范围。

二级基准必须依附于一级基准。

# 5. 几何元素提取规范

## 5.1 直线提取

需要识别：

- 水平线；
- 垂直线；
- 斜线；
- 轮廓线；
- 台阶线；
- 槽边线；
- 投影线；
- 剖切线。

记录内容：

```text
line_id
start_x
start_y
end_x
end_y
line_type
line_weight
belongs_to_view
```

审计要求：

- 水平线的 y 坐标应一致；
- 垂直线的 x 坐标应一致；
- 对称线两侧距离应一致；
- 台阶线不得悬空；
- 轮廓线必须闭合或有明确端点。

## 5.2 圆提取

圆类元素包括：

- 圆孔；
- 圆台；
- 外圆；
- 内孔；
- 沉孔；
- 环形台阶；
- 偏心孔；
- 圆弧轮廓。

记录内容：

```text
circle_id
center_x
center_y
radius
line_type
belongs_to_view
is_hole
is_visible
```

审计要求：

- 同心圆中心误差应为 0；
- 圆心必须落在中心线交点；
- 左右对称孔必须镜像；
- 半圆端头半径必须与宽度匹配；
- 圆不能画成椭圆，除非是投影结果或斜截面断面。

## 5.3 圆弧提取

圆弧类元素包括：

- U 形槽底部圆弧；
- 半圆端头；
- 圆角过渡；
- 弧形支架；
- 旋转体轮廓。

记录内容：

```text
arc_id
center_x
center_y
radius
start_angle
end_angle
start_point
end_point
tangent_relation
```

审计要求：

- 圆弧端点必须连接直线；
- U 形槽圆弧必须与两侧直线相切；
- 半圆端头中心必须在中心线上；
- 弧形零件的内外圆弧应保持等距或题图所示厚度。

## 5.4 多段线提取

用于描述复杂台阶轮廓：

```text
polyline_id
points = [(x1,y1), (x2,y2), ...]
closed = true/false
line_type
```

审计要求：

- 台阶应为水平/垂直折线；
- 端点必须相接；
- 不得出现无意义短线；
- 外轮廓必须连续。

# 6. 标准线型规范

## 6.1 可见轮廓线

用途：

- 外轮廓；
- 可见棱边；
- 可见孔边；
- 可见槽边。

规范：

- 用粗实线；
- 连续不断；
- 不得被中心线或虚线覆盖；
- 外轮廓优先级最高。

## 6.2 不可见轮廓线

用途：

- 被遮挡的孔；
- 被遮挡的槽；
- 内部台阶；
- 背面轮廓。

规范：

- 用细虚线；
- 虚线段长度一致；
- 虚线不得穿过实体可见轮廓后继续乱画；
- 剖视图中通常应减少不必要虚线。

## 6.3 中心线

用途：

- 圆孔轴线；
- 对称轴；
- 回转体轴线；
- 剖切中心基准。

规范：

- 用细点画线；
- 必须穿过圆心；
- 应超出轮廓线少许；
- 两个方向中心线交于圆心；
- 不得用实线代替；
- 不得过短。

## 6.4 剖面线

用途：

- 表示被剖切实体材料。

规范：

- 细实线；
- 通常 45°；
- 间距均匀；
- 同一零件剖面线方向一致；
- 相邻不同零件可改变方向或间距；
- 只能画在实体材料区域；
- 孔、槽、空腔不画剖面线；
- 剖面线不得压住中心线和孔边界。

## 6.5 波浪线

用途：

- 局部剖边界；
- 断裂边界。

规范：

- 细实线；
- 自由曲线；
- 不得与轮廓线重合；
- 不得穿越需要保留的轮廓；
- 表示局部剖切范围。

## 6.6 剖切符号线

用途：

- 表示剖切位置；
- 表示剖视方向；
- 标注 A-A、B-B。

规范：

- 剖切位置明确；
- 箭头方向明确；
- 字母标注一致；
- 剖视图标题与剖切符号对应。

# 7. 视图绘制标准流程

## 7.1 主视图

主视图一般表达零件主要形状。

步骤：

1. 确定主视方向；
2. 画中心线；
3. 画最大外轮廓；
4. 画主要孔、槽、台阶；
5. 补充可见细节；
6. 补充必要虚线；
7. 检查对称性和投影关系。

审计：

- 是否表达最主要形状；
- 轮廓是否连续；
- 孔是否定位准确；
- 中心线是否穿过圆心；
- 虚线是否必要。

## 7.2 俯视图

俯视图与主视图必须长对正。

步骤：

1. 从主视图向俯视图投影长度；
2. 从左视图或已知宽度确定宽度；
3. 画水平中心线和竖直中心线；
4. 画外轮廓；
5. 画孔、槽、圆弧；
6. 画隐藏线；
7. 校核“长对正、宽相等”。

审计：

- 与主视图 X 坐标对应；
- 圆心是否投影一致；
- 槽宽是否一致；
- 隐藏线是否和其他视图对应。

## 7.3 左视图

左视图与主视图必须高平齐，与俯视图宽相等。

步骤：

1. 从主视图投影高度；
2. 从俯视图转移宽度；
3. 建立竖直中心线和水平中心线；
4. 画外轮廓；
5. 画台阶、孔、槽；
6. 画隐藏线或剖切部分；
7. 校核“高平齐、宽相等”。

审计：

- 高度与主视图一致；
- 宽度与俯视图一致；
- 孔中心高度一致；
- 台阶位置一致。

# 8. 投影关系审计

## 8.1 三视图基本规律

必须满足：

```text
主视图与俯视图：长对正
主视图与左视图：高平齐
俯视图与左视图：宽相等
```

## 8.2 横向审计

检查：

- 主视图中心线 X；
- 俯视图中心线 X；
- 左右边界 X；
- 孔中心 X；
- 槽边 X；
- 台阶边 X。

合格：

- 对应 X 坐标一致；
- 对称结构左右等距；
- 圆孔中心不偏。

## 8.3 纵向审计

检查：

- 主视图高度；
- 左视图高度；
- 孔中心高度；
- 台阶高度；
- 底面高度；
- 上端面高度。

合格：

- 对应 Y 坐标一致；
- 高度不漂移；
- 台阶不错层。

## 8.4 宽度转移审计

检查：

- 俯视图宽度；
- 左视图宽度；
- 孔的前后位置；
- 槽的前后位置；
- 凸台厚度。

合格：

- 宽度转移正确；
- 前后位置不反；
- 视图方向不镜像错误。

---

# 9. 剖视图处理规范

## 9.1 全剖视图

适用：

- 内部结构复杂；
- 剖切面通过对称中心；
- 需要完整表达内部结构。

流程：

1. 确定剖切位置；
2. 沿剖切面切开；
3. 去掉靠近观察者的一半；
4. 画剩余部分轮廓；
5. 对实体材料画剖面线；
6. 孔、槽、空腔留白；
7. 删除不必要虚线。

审计：

- 剖切位置正确；
- 实体全部剖切；
- 孔槽不剖；
- 剖面线完整；
- 后方虚线不过多。

## 9.2 半剖视图

适用：

- 零件内外形都需要表达；
- 零件基本对称。

流程：

1. 确定对称中心线；
2. 一半画外形；
3. 另一半画剖视；
4. 以中心线为分界；
5. 剖切侧实体加剖面线；
6. 外形侧保留必要虚线；
7. 剖切侧一般少画虚线。

审计：

- 分界是否为中心线；
- 左右是否混乱；
- 剖面线只在剖切侧；
- 孔槽是否留白；
- 外形侧是否保留可见外轮廓。

## 9.3 局部剖视图

适用：

- 只需表达局部内部结构；
- 不需要全剖或半剖。

流程：

1. 确定局部剖切范围；
2. 在需要表达处切开；
3. 用波浪线表示局部剖边界；
4. 局部实体加剖面线；
5. 其他区域保持原外形视图。

审计：

- 波浪线位置合理；
- 波浪线不与轮廓重合；
- 只剖局部；
- 未剖区域不加剖面线；
- 局部剖不破坏整体外形。

## 9.4 旋转剖视图

适用：

- 剖切面经过偏置结构；
- 需要把倾斜或偏心结构旋转到投影面表达。

流程：

1. 确定剖切路径；
2. 判断需要旋转的剖切面；
3. 将偏置剖切面旋转到主剖切平面；
4. 绘制旋转后的剖面轮廓；
5. 实体加剖面线；
6. 孔槽留白。

审计：

- 是否正确理解旋转方向；
- 偏心孔是否旋到剖面中；
- 是否误按普通直剖绘制；
- 剖面线是否只在实体内。

## 9.5 阶梯剖视图

适用：

- 多个内部结构不在同一剖切平面；
- 通过折线剖切表达多个孔槽。

流程：

1. 确定折线剖切路径；
2. 将不同剖切段展开到同一剖视图；
3. 不画剖切面转折处的分界线；
4. 实体加剖面线；
5. 孔槽留白。

审计：

- 折线剖切路径是否正确；
- 转折处是否错误画线；
- 各结构是否展开到同一剖视图；
- 剖面线方向一致。

# 10. 断面图处理规范

## 10.1 重合断面图

适用：

- 断面直接画在原视图轮廓内；
- 图形简单；
- 不影响原图识读。

规范：

- 断面轮廓用细实线；
- 剖面线画在断面区域；
- 原轮廓仍保持清晰。

## 10.2 移出断面图

适用：

- 断面形状需要单独表达；
- 原视图内容较复杂。

流程：

1. 确定断面位置；
2. 按切割处真实截面形状绘制；
3. 将断面移出到旁边；
4. 标明断面名称；
5. 加剖面线。

审计：

- 断面形状是否真实；
- 是否与切割方向对应；
- 是否错误画成投影视图；
- 剖面线是否完整；
- 标注是否清楚。

# 11. 漏线补画题标准流程

## 11.1 漏线类型

常见漏线包括：

- 可见轮廓线漏画；
- 不可见虚线漏画；
- 中心线漏画；
- 圆孔线漏画；
- 台阶转折线漏画；
- 剖面轮廓线漏画；
- 剖面线漏画；
- 对称结构另一侧漏画。

## 11.2 补线原则

不得“见空就补”，必须判断线的性质。

判断顺序：

1. 该线是否真实存在？
2. 在该视图中是否可见？
3. 是否被遮挡？
4. 是否被剖切？
5. 是否应作为中心线？
6. 是否因剖视规则应省略？
7. 是否和其他视图投影对应？

## 11.3 补线流程

1. 先识别已知视图；
2. 建立投影关系；
3. 找出缺失区域；
4. 从其他视图投影确定线的位置；
5. 判断线型；
6. 补画；
7. 复核是否多画。

## 11.4 漏线补画审计

- 漏线是否全部补齐；
- 是否补了不该有的线；
- 虚线是否表示不可见结构；
- 中心线是否贯穿圆心；
- 剖视图中是否避免多余虚线；
- 剖面线是否只在实体内；
- 补线是否和其他视图投影对应。

- 缩放后剖面线间距不能过密或过疏。

# 13. 剖面线生成标准

## 13.1 剖面线角度

默认 45°。

特殊情况：

- 若主要轮廓线也是 45°，可改为 30°或 60°；
- 同一零件必须方向一致；
- 不同零件相邻时可改变方向或间距。

## 13.2 剖面线裁剪

剖面线必须被裁剪在实体材料区域内。

不得穿过：

- 圆孔；
- 长圆槽；
- U 形槽；
- 空腔；
- 沉孔空白区；
- 轴孔；
- 销孔；
- 断开边界外区域。

## 13.3 剖面线间距

要求：

- 间距均匀；
- 不过密；
- 不过疏；
- 不因区域大小变化而随机改变；
- 小区域可适当减少数量，但方向一致。

## 13.4 剖面线审计

检查：

- 是否漏画实体区域；
- 是否误画孔槽区域；
- 是否角度统一；
- 是否压住重要轮廓；
- 是否与相邻结构混淆。

# 14. 文字说明标准

每张答案图应包含以下内容。

## 14.1 标题

格式建议：

```text
第XX题  题型名称（答案）
```

例如：

```text
第17题  半剖左视图（答案）
第13、14题  漏线补画（答案）
第22、23题  旋转全剖与半剖俯视图（答案）
```

## 14.2 作图步骤

每题建议 4–6 条。

格式：

```text
作图步骤
1. 确定中心线和投影基准。
2. 根据已知视图绘制主要外轮廓。
3. 补画孔、槽、台阶等内部结构。
4. 按题目要求绘制剖视或断面。
5. 检查线型、投影关系和剖面线。
```

## 14.3 要点说明

用于解释关键规则。

例如：

```text
要点说明
• 半剖以中心线为界，一半外形，一半剖视。
• 剖面线只画在实体材料内。
• 孔、槽、空腔不画剖面线。
• 中心线必须穿过圆心并适当伸出轮廓。
```

## 14.4 军事化审计

每张图必须有审计清单。

建议格式：

```text
【军事化审计】
☑ 中心线正确：所有圆孔中心线贯穿圆心。
☑ 投影关系正确：长对正、高平齐、宽相等。
☑ 线型正确：粗实线、虚线、中心线区分清楚。
☑ 剖面线正确：只画实体，不画孔槽。
☑ 比例正确：主要圆心距、宽高关系与原图一致。
☑ 版面正确：图形和文字无重叠、无截断。
```

# 17. 机械制图常见错误清单

## 17.1 几何错误

- 圆心偏移；
- 同心圆不同心；
- U 形槽不对称；
- 圆弧与直线不相切；
- 台阶错位；
- 视图宽度不一致；
- 左右比例不一致。

## 17.2 投影错误

- 主视图和俯视图未长对正；
- 主视图和左视图未高平齐；
- 俯视图和左视图宽度不等；
- 孔中心跨视图不对应；
- 台阶高度跨视图不对应；
- 前后方向画反。

## 17.3 剖切错误

- 孔被画上剖面线；
- 槽被画上剖面线；
- 半剖分界线错误；
- 局部剖范围过大；
- 全剖保留过多虚线；
- 旋转剖没有旋转；
- 阶梯剖画出转折线。

## 17.4 线型错误

- 中心线画成实线；
- 虚线画成实线；
- 剖面线太粗；
- 轮廓线太细；
- 虚线穿过不该穿过的区域；
- 中心线没有伸出轮廓；
- 线条层级混乱。

## 17.5 版面错误

- 图形压文字；
- 文字压线；
- 标题不居中；
- 图太小；
- 图太靠边；
- PDF 裁切；
- PNG 分辨率低。
